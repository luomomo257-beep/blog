# 欢迎来到我的小站

这是你的第一篇博客文章。博客基于 **GitHub Pages + GitHub Actions** 搭建，
每天会自动生成一篇「每日更新」文章（一言 + 生活冷知识 + 编程小贴士）。

## 怎么发布新文章

1. 在 `posts/` 目录新建文件，命名格式必须是：`YYYY-MM-DD-标题.md`
2. 用 Markdown 写内容
3. 推送到 GitHub 仓库，博客自动更新（约 1 分钟内生效）

## 支持哪些 Markdown 格式

- **加粗**、*斜体*、~~删除线~~、`行内代码`
- 无序列表、有序列表
- [超链接](https://github.com)
- 引用块
- 代码块
- 表格

### 代码块示例

```python
def hello(name: str) -> str:
    return f"你好，{name}！"
```

### 表格示例

| 板块 | 内容 | 更新频率 |
| ---- | ---- | ---- |
| 手动文章 | 你自己写 | 由你决定 |
| 每日更新 | 一言 + 冷知识 + 编程贴士 | 每天 06:00 |

> 提示：把 `scripts/generate.py` 里的 `SITE_NAME`、`AUTHOR`、`SITE_URL` 改成你自己的信息。
