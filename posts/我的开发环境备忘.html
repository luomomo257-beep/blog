我的开发环境备忘

2026-09-17 · 博主 · 编程

类型: 编程

记录一下常用的开发环境和命令，方便随时查阅。

Python

  • 管理多个项目依赖：python -m venv .venv 建虚拟环境，激活后 pip install -r requirements.txt
  • 批量统计词频：from collections import Counter
  • 排查安装报错：先看是不是 pip 版本问题，python -m pip install --upgrade pip 再重试

Git

场景 命令
改写上一次提交信息 git commit --amend
撤销提交但保留改动 git reset --soft HEAD~1
找回误删的未提交文件 git checkout -- 文件名
查看分支合并历史 git log --oneline --graph

前端

  • 长列表滚动卡顿：给容器加 content-visibility: auto
  • 图片加载提速：加 loading="lazy" 和 decoding="async"
  • flex/grid 间距：直接用 gap，别再写 margin hack
