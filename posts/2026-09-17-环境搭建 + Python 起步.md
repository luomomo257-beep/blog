## 二、知识点总结

### 2.1 虚拟环境 venv

- **是什么**：Python 自带的虚拟环境工具，为每个项目创建独立的包环境。

- **为什么用**：不同项目依赖的包版本互不干扰，避免污染系统 Python，也避免系统装包权限问题。

- **命令**（Windows / PowerShell）：

```
\# 创建（在项目目录下）

python -m venv .venv

\# 激活

.venv\Scripts\Activate.ps1

\# 验证：命令行前面出现 (.venv) 即成功

python --version
```

> ⚠️ 装任何包（pip install）都必须在激活状态下执行。

### 2.2 变量与数据类型

| 类型    | 说明   | 示例             | 转换函数   |
| ------- | ------ | ---------------- | ---------- |
| `int`   | 整数   | `25`             | `int(x)`   |
| `float` | 浮点数 | `25.0`           | `float(x)` |
| `str`   | 字符串 | `"深圳"`         | `str(x)`   |
| `bool`  | 布尔   | `True` / `False` | `bool(x)`  |

**核心规则**：

- 变量命名：字母 / 下划线开头，不能数字开头，不用关键字。

- `input()` 返回的**永远是字符串**，做数学运算前必须转换。

- `bool()` 转换：空值（0、""、None、空容器）为 `False`，其余为 `True`。

### 2.3 输入输出与 f-string

```
name = input("请输入姓名：")        # input 一定返回 str

age = int(input("请输入年龄："))     # 需要数字时手动转换

\# f-string：{} 内直接放变量或表达式

print(f"我是{name}，今年{age}岁，来自深圳，喜欢写代码")

\# 字面花括号用双写转义

print(f"输出一对花括号：{{}}")       # -> 输出一对花括号：{}
```

**中文不乱码的条件**：Python 3 默认 UTF-8，关键是**编辑器保存文件时选 UTF-8 编码**。


## 四、自测 4 题与答案

| #   | 题目                              | 答案                                                                 |
| --- | --------------------------------- | -------------------------------------------------------------------- |
| ①   | `"10" + 5` 会报错还是输出 15？    | **报错**。str 和 int 不能直接相加，需先 `int("10")` 或 `str(5)`      |
| ②   | `bool(0)` 和 `bool("0")` 分别是？ | `bool(0)` = **False**；`bool("0")` = **True**（非空字符串都为 True） |
| ③   | `x = 5`，`if x = 5:` 合法吗？     | **不合法**。`=` 是赋值，条件判断要用 `==`，直接语法错误              |
| ④   | f-string 里输出字面花括号 `{}`？  | 写两个花括号 `{{}}`                                                  |

## 五、易错点（今日踩坑记录）

1. **venv 没激活就装包** → 包装进了系统 Python，项目间互相污染。

2. **input () 忘记类型转换** → `"25" * 1.8` 直接 TypeError。

3. `=`**&#x20;与&#x20;**`==`**&#x20;混用** → 赋值和比较不分，语法错误。

4. **中文乱码** → 编辑器保存编码不是 UTF-8。

5. **类型混加** → str 和 int 不能直接 `+`。
